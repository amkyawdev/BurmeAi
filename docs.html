Getting Started

How to Use

  1. Open the app at burme-ai.vercel.app
  2. Choose Chat or Speak feature
  3. Start chatting or convert text to speech

Features

AI Chat

Chat with AI-powered assistant that understands Burmese language

Text to Speech

Convert Burmese text to natural speech audio

Download Audio

Save generated speech as WAV file

API Endpoints

POST
/api/chat

Chat with AI assistant

{
  "message": "မင်္ဂလာပါ"
}
POST
/api/speak

Convert text to speech

{
  "text": "မြန်မာစာ"
}
