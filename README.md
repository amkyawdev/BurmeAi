# BurmeAi Frontend

AI-powered web application for Burmese language support.

## 🌐 Live Demo

https://burme-ai.vercel.app

## 📁 Pages

- `index.html` - Homepage
- `chat.html` - AI Chat
- `speak.html` - Text-to-Speech
- `docs.html` - Documentation
- `about.html` - About/Contact

## 🛠️ Tech Stack

- HTML5 / CSS3 / JavaScript
- Bootstrap Icons
- Vercel Hosting

## 📦 Deploy to Vercel

```bash
npm install -g vercel
vercel
```
